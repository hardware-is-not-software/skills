# Acceptance Checklist

Use binary checks (`PASS` / `FAIL`) and keep checks specific.

## Diagram Identity
- [ ] Diagram contains all required entities from original prompt.
- [ ] Entity names exactly match required text.
- [ ] Directionality of flows/connections matches prompt/reference.

## Layout And Geometry
- [ ] Main groups are placed in correct relative positions.
- [ ] Alignment and spacing follow target reference.
- [ ] No overlaps or unintended crowding.
- [ ] Edge routing style matches target (orthogonal/curved).
- [ ] Arrows are straight and have no unnecessary bends.

## Style Fidelity
- [ ] Shape families match requested/reference style.
- [ ] Fill/stroke colors match agreed palette.
- [ ] Typography (family/size/weight) matches agreed style.
- [ ] Visual hierarchy (emphasis levels) matches target.

## Legibility And Quality
- [ ] No truncated labels.
- [ ] No low-contrast text.
- [ ] No dangling connectors.
- [ ] No regressions in previously passed checks.

- P1 checks passed:
- Remaining P2 issues (if accepted):
